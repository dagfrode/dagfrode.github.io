# Accessibility resources

> You can be compliant with WCAG but still have a webpage that is not accessible to most people.

Curated resources for the accessibility game projects. Each section is ordered most-useful first. **⭐ Anbefalt** marks the core resources to start with; the rest is useful further reading.

## Start here

- **⭐ Anbefalt** [WCAG 2.2](https://www.w3.org/TR/WCAG22/) — the current international standard for digital accessibility
- **⭐ Anbefalt** [How People with Disabilities Use the Web](https://www.w3.org/WAI/people-use-web/) — essential reading before any design work
- [WCAG 2 Overview](https://www.w3.org/WAI/standards-guidelines/wcag/) — orientation to the WCAG family
- [WCAG 3 (draft)](https://www.w3.org/WAI/standards-guidelines/wcag/wcag3-intro/) — where the standard is heading
- [Teaching Accessible Computing](https://bookish.press/tac) — web book, useful for both students and educators

## Testing tools

Developers use these to find and fix accessibility issues. Useful to know when designing what knowledge a game should build.

- [Axe DevTools](https://www.deque.com/axe/devtools/) — the most widely used automated accessibility scanner (browser extension)
- [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) — check colour contrast ratios against WCAG
- [Color.review](https://color.review/) — visual contrast exploration
- [Color Blind Web Page Filter](https://www.toptal.com/designers/colorfilter) — simulate how pages look with different colour vision deficiencies

**Screen readers** — try one out to understand how your interface sounds. Your phone already has one built in, and mobile screen readers are more predictable than desktop ones, which makes them a good place to start.

- **⭐ Anbefalt** [Android TalkBack](https://support.google.com/accessibility/android/answer/6283677) — built into Android; how to turn it on and the basic gestures
- **⭐ Anbefalt** [iOS VoiceOver](https://support.apple.com/guide/iphone/turn-on-and-practice-voiceover-iph3e2e415f/ios) — built into iPhone/iPad, with a built-in practice mode
- [NVDA](https://www.nvaccess.org/download/) — free screen reader for Windows, widely used for desktop testing
